# Engineering Reflection & Key Takeaways

## 1. Technical Growth
Throughout these tasks, I deepened my understanding of semantic web standards. Writing code that is inherently accessible (using proper ARIA roles, semantic landmarks, and keyboard navigation) reinforced that web development is about building for *all* users. Transitioning from basic static layouts to responsive CSS Grid systems and asynchronous JavaScript API integrations significantly enhanced my ability to build dynamic, data-driven web applications.

## 2. Challenges Overcome
* **Asynchronous Error Handling**: Managing edge cases when fetching external data from the GitHub API required implementing robust error boundaries and loading states so the user interface never breaks.
* **Theme Persistence**: Ensuring smooth transitions between light and dark themes without flashing required careful CSS variable scoping combined with `localStorage` state management.

## 3. Future Enhancements
* Integrating a headless CMS or database for dynamic blog management.
* Expanding automated testing suites with Jest and Playwright.
